# ESP Quiz — Banco de Questões Interativo 🎯

Aplicação web interativa para prática e resolução de questões de concursos/exames, com filtragem por disciplina, nível de dificuldade, pontuação e modo escuro/claro.

## 🚀 Tecnologias

- **HTML5** & **CSS3** (Design responsivo e temas Dark/Light)
- **JavaScript (ES6+)**
- Totalmente estático (sem dependência de servidor ou backend complexo)

## 📦 Como Executar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador web ou usar extensões como o Live Server no VS Code.

## 🌐 Hospedagem (GitHub Pages)

Este projeto está pronto para ser publicado gratuitamente via **GitHub Pages**:
1. No repositório no GitHub, vá em **Settings** > **Pages**.
2. Em **Source**, selecione a branch `main` e a pasta `/ (root)`.
3. Clique em **Save**. Em instantes, o site estará disponível online.
